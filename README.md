# build-2611-12 · 도면 기반 원소재 가격 변동 · 제품 단가 영향 분석

생성형 AI 업무자동화 전문가과정 **2차수** 수강생 프로젝트 12 — 기획 양재현.

**바로 쓰기: https://aebonlee.github.io/build-2611-12/**

도면 PDF 에서 재질·치수·중량을 읽고, 올린 원자재 Index 엑셀로 분석 기간의 가격 변동률을 구해
소재 원가 × 변동률만큼 제품 단가가 얼마나 움직였어야 하는지 계산합니다.
정확히 맞는 Index 가 없으면 같은 계열 후보를 가격 움직임(월간 변동률 상관)으로 비교해 「추정 — 담당자 확인」으로 보여 줍니다.
파일은 브라우저 안에서만 처리하며 서버로 올라가지 않습니다. 도면은 외부 AI 로 보내지 않습니다.

| 파일 | 역할 |
|---|---|
| `js/costidx.js` | 계산 엔진(재질 동의어 · 도면 글자 추출 · 중량 · Index 엑셀 읽기 · 기간 값 · 상관 · 매칭 · 단가 영향 · 엑셀 시트) — 계산은 전부 여기 |
| `js/app.js` | 화면(PDF 읽기 · 품목 편집 · 매핑 표 · SVG 그래프 · 엑셀 내려받기) |
| `samples/` | 가짜 예제 도면 PDF 3장(1장은 글자 없는 스캔 흉내) · 가짜 원자재 가격 통합문서 `index-workbook_sample.xlsx` 와 생성 스크립트 `make-samples.js` |
| `test/logic.test.js` | 계산 규칙 테스트 `node test/logic.test.js` |
| `test/smoke.browser.js` | 화면 연기 테스트(playwright) |
| `CLAUDE.md` | 작업 지시서 + 기획서 원문 |

예제 데이터는 실제 사내 데이터가 아닙니다(가짜 도면 3장 · 실무 「원자재 가격 동향」 형식을 흉내 낸 가짜 통합문서 5시트).

v1.1 부터 실무 원자재 가격 통합문서(시트 여러 장 · 머리 블록 · 병합 품목명 · 증감률 열 · 최신이 위)를 그대로 읽고, 규격 칸의 재질로 Index 를 맞춥니다. v1.0 단순 표(날짜 열 + Index 열)도 계속 읽습니다.
