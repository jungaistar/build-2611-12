도면 기반 원소재 가격 변동 · 제품 단가 영향 분석

도면에서 재질·치수·중량을 읽고, 올린 원자재 Index 엑셀로 분석 기간의 가격 변동률을 구해 소재 원가 × 변동률만큼 제품 단가가 얼마나 움직였어야 하는지 계산합니다. 맞는 Index 가 없으면 가격 움직임이 비슷한 후보를 추정으로 보여 줍니다.

1. 도면을 올리세요

글자로 된 PDF 는 재질·치수·중량·수량을 자동으로 찾아 「보조 추출」로 보여 줍니다. 스캔 도면은 아래 품목에서 재질과 중량을 직접 넣으세요.

예제 데이터는 실제 사내 데이터가 아닙니다 — 가짜 도면 3장(그중 1장은 글자 없는 스캔)과 가짜 원자재 가격 통합문서(시트 5장 · 2020-01~2026-10, 출처 「가상 자료」)입니다. 예제 도면 PDF: BRK-2611-A · PIN-2611-B · BSH-2611-C(스캔) · 예제 통합문서: index-workbook_sample.xlsx

2. 품목 · 단가 · 원가 구성

값 옆 꼬리표가 출처입니다 — 도면에서 읽음 직접 입력 계산 가정. 빈 칸으로 둔 수율·스크랩 회수율·절단 여유는 가정 기본값을 씁니다. 가공 여유는 소재 규격(가공 전 치수)에 넣어 적으세요.

3. 원자재 Index 엑셀 · 분석 기간

엑셀에 있는 Index 만 씁니다. 인터넷 시세나 다른 가격은 쓰지 않습니다. 열마다 이름 · 단위 · 출처를 읽어 아래 표에 보여 줍니다. 역할(Index · 참고 계열 · 쓰지 않음)과 재질 계열을 확인하고 고치세요. 단위가 비어 있는 숫자 열(전월 대비 증감률)과 분기 열은 Index 로 쓰지 않습니다.

4. 원소재 ↔ Index 매칭

재질 계열과 같은 Index 가 있으면 그것만 씁니다. 없으면 같은 계열 후보를 재질 유사도와 분석 기간의 가격 움직임(월간 변동률 상관)으로 비교해 보여 주고 추정 — 담당자 확인으로 표시합니다. 유사 Index 는 실제 원소재 가격이 아니라 가격 변동을 추정하는 대체 지표입니다.
