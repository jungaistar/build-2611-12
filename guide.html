사용법

협력업체 단가 인상 요청을 원소재 가격 변동으로 확인합니다

도면 → 품목·원가 구성 → Index 엑셀·기간 → 매칭 → 결과 → 엑셀 보고서 순서입니다. 모든 계산은 이 브라우저 안에서 끝나고 도면과 구매 데이터는 어디로도 올라가지 않습니다.

1. 도면 PDF

글자로 된 PDF(CAD 에서 PDF 로 저장한 도면)는 표제란에서 품명 · 도면번호 · 재질 · 중량 · 수량 · 치수를 찾아 「보조 추출」로 보여 줍니다. 찾은 값마다 몇째 줄에서 읽었는지 함께 보여 주니 원문과 맞는지 확인하세요.

스캔한 도면은 글자가 없어 읽지 못합니다. 품목에서 재질과 중량(또는 치수)을 직접 넣으세요. 도면 이미지를 외부 AI 로 보내 읽게 하는 기능은 넣지 않았습니다 — 사내 도면을 외부로 보내지 않기 위해서입니다.

찾는 항목표제란 표기 예
재질MATERIAL: SCM440H · 재질: SM45C · MAT'L SUS304
중량WEIGHT: 3.6 kg · 중량 : 850 g
완성 치수SIZE: Ø45 x 210 L · t12 x 150 x 300 · OD60 x t8 x 80
소재 규격(가공 전)STOCK: Ø50 x 215 L · 소재 규격: PL t12 x 160 x 310

2. 품목 · 단가 · 원가 구성

기준 단가(분석 시작 시점의 구매 단가, 1 EA)를 넣습니다. 협력업체가 요청한 단가나 현재 단가가 있으면 「요청·현재 단가」에 넣으면 원소재 변동만으로 설명되는지 비교합니다.

원가 구성은 기준 단가 대비 비율(%) 또는 금액(원)으로 넣습니다. 가공비 · 인건비 · 제조경비는 Index 영향을 받지 않는 별도 항목으로 따로 보여 줍니다.

  • 소재 원가 = 유효 중량 × 소재 단가(원/kg). 소재 단가를 비우면 원가 구성의 소재비를 씁니다.
  • 투입 중량 — 소재 규격이 있으면 그 치수(길이 + 절단 여유) × 비중, 없으면 완성 중량 ÷ 수율입니다. 가공 여유는 소재 규격 치수에 넣어 적으세요.
  • 스크랩 회수율 — 깎여 나간 스크랩 중량 가운데 소재 값으로 돌려받는 비율입니다. 유효 중량 = 투입 − 스크랩 × 회수율.
  • 수율 · 스크랩 회수율 · 절단 여유를 비우면 가정 기본값(수율 0.85 · 회수율 0.3 · 절단 여유 3mm)을 쓰고 「가정」 꼬리표를 붙입니다.
  • 소재가 둘 이상이면 「소재 줄 추가」로 줄을 늘립니다. 소재별 영향을 합산합니다.

3. 원자재 Index 엑셀 · 분석 기간

날짜 열 하나와 Index 열 여러 개가 있으면 됩니다. 첫 줄 위에 제목 줄이 있어도 머리줄을 찾아 읽고, 시트가 여럿이면 고를 수 있습니다. 열마다 「Index 로 사용 · 참고 계열 · 쓰지 않음」과 재질 계열을 확인하세요(열 이름에서 추정합니다).

일·주 단위 값은 월평균으로 맞춥니다. 빈 칸 · 숫자가 아닌 칸 · 읽을 수 없는 날짜는 그 달만 비우고 알림으로 보여 줍니다. 시작월 · 종료월에 값이 없으면 가장 가까운 이전 달 값을 쓰고 사용한 월을 표시합니다.

Index 단위(원/톤 · USD/톤 · 지수)는 상관없습니다. 변동률(종료 ÷ 시작 − 1)만 씁니다.

실무 「원자재 가격 동향」 통합문서(v1.1)

  • 시트를 모두 한 번에 읽습니다. A열의 Item · 지역 · 기준 · 단위 · 규격 · 출처 · 상세출처 · 주소 줄(머리 블록)을 찾고, 가로로 병합된 품목명은 오른쪽 열이 이어받습니다.
  • 연 · 월이 두 칸(「2026년」 「10월」)이든 한 칸(「2026-5」)이든 읽고, 최신 월이 위에 있어도 오래된 순으로 정렬합니다. 분기 열과 단위가 빈 증감률 열은 Index 로 쓰지 않습니다.
  • Index 이름은 「품목 · 규격 · 기준 · 지역 · 단위」로 만듭니다. 규격 칸의 재질(SCM440 · SS400 · STS304 …)이 원소재와 같으면 규격 재질 일치, SMxxC · SCRxxx 같은 묶음 표기에 들어가면 계열 일치로 씁니다. 같은 조건이 여럿이면 한국 · KRW/kg 을 먼저 고릅니다.
  • 비철처럼 USD/ton 과 KRW/kg(환산) 열이 짝이면 원화 열을 기본으로 씁니다. 출처가 구매팀인 열은 사내 구매가로 보고 「참고 계열」로 둡니다(Index 로 쓰지 않음). 환율 · PMI · PPI · 운임 시트는 기본 「쓰지 않음」입니다.
  • 「원화 환산」을 켜면 USD · RMB 단위 Index 를 같은 통합문서의 환율 시트로 그 달 환율을 곱해 바꿉니다. 바꾼 값은 「계산」으로 표시합니다. 단위가 다른 Index 는 결과 표에서 단위별로 따로 묶습니다.
  • 적용한 Index 마다 시트 · 열 · 기준 · 지역 · 출처 · 상세출처 · 주소를 근거로 보여 주고 엑셀 보고서에도 남깁니다.

4. 매칭 — 정확 일치와 추정

  • 정확 일치 — 재질 계열과 같은 Index 가 하나면 그것만 씁니다. 다른 Index 를 임의로 고르지 않습니다.
  • 여러 Index 일치 — 같은 계열 Index 가 여럿이면 담당자가 고를 때까지 계산하지 않습니다.
  • 추정 — 정확한 Index 가 없으면 같은 계열 후보(예: S45C → 특수강 · 열연 · 냉연)를 재질 유사도와 분석 기간의 월간 변동률 상관으로 점수를 매겨 3개까지 보여 줍니다. 점수 = 재질 유사도 × 0.4 + 상관 × 0.6.
  • 그 원소재 자체의 가격 계열이 엑셀에 없으면 후보끼리의 움직임 일치도를 비교합니다. 실제 구매가 이력 열이 있으면 「참고 계열」로 지정해 그것과 비교하세요 — 참고 계열은 계산에 쓰지 않습니다.
  • 분석 불가 — 같은 계열 후보가 없으면(예: 알루미늄인데 철강 Index 만 있음) 임의로 고르지 않습니다.

유사 Index 는 실제 원소재 가격이 아니라 가격 변동을 추정하는 대체 지표입니다. 후보 사이 변동률 차이가 크면 결과가 Index 선택에 크게 달라진다고 알려 줍니다.

5. 결과 · 검증 · 보고서

원가 증감액 = 소재 원가 × Index 변동률, 단가 대비 영향률 = 원가 증감액 ÷ 기준 단가, 예상 단가 = 기준 단가 + 원가 증감액입니다.

요청·현재 단가가 있으면 실제 변동에서 소재 영향을 뺀 「설명 안 되는 차이」가 허용 범위(기준 단가의 1%, 바꿀 수 있음)를 넘는지 봅니다. 원소재 가격은 내렸는데 단가가 오른 경우는 따로 표시합니다.

엑셀 보고서는 도면별분석 · Index매칭 · 가격변동(분석 기간 월별 원자료) · 단가영향 · 종합 · 근거가정 여섯 시트입니다. 근거가정 시트에 Index 출처(파일 · 시트 · 열)와 수식 · 가정값을 적습니다.

6. 이번 판에서 하지 않는 것

  • 스캔 도면 글자 읽기(OCR)와 형상(그림)에서 치수 읽기 — 글자 PDF 의 표제란 글자만 읽습니다.
  • 봉재 · 판재 · 파이프 밖의 형상(단조 · 주물 · 복잡 형상) 중량 계산 — 도면 중량이나 직접 입력 중량을 씁니다.
  • 외부 시세 · 인터넷 검색 · 엑셀에 없는 Index — 쓰지 않습니다.
  • 환율 환산 — USD Index 도 변동률만 쓰므로 환율 변동은 따로 반영하지 않습니다.
